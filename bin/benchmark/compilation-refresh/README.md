# Complete compilation-table refresh

Measure the 50 retained `gopurs-*` corpora and a fresh b8x Go corpus with all
three installed gopurs hosts, then measure `purust-aff` with both Purust hosts.
The tools retain input/compiler manifests, raw phase logs, all samples and
byte-exact output evidence. Identical generated bytes are stored once per case.

Run the stages **serially**, from the `altbak.pub` root. Long stages should be
background jobs. `ARCHIVE` names a new campaign directory.

```sh
node bin/benchmark/compilation-refresh/prepare.mjs "$ARCHIVE"
node bin/benchmark/compilation-refresh/measure.mjs "$ARCHIVE" libraries
node bin/benchmark/compilation-refresh/prepare-extra.mjs "$ARCHIVE"
node bin/benchmark/compilation-refresh/measure.mjs "$ARCHIVE" extra \
  "$ARCHIVE/cases/b8x/definition.json" \
  "$ARCHIVE/cases/purust-aff/definition.json"
node bin/benchmark/compilation-refresh/validate.mjs "$ARCHIVE"
node bin/benchmark/compilation-refresh/publish.mjs "$ARCHIVE"
```

`prepare.mjs` checks the installed binaries against the final corrected-host
qualification and clones the previously qualified library inputs/oracles.
`prepare-extra.mjs` rebuilds the b8x frontend from current frozen sources and
verifies Purust Aff's cached frontend against its recorded SHA-512 source hashes.
The initial archive preserves the README and compiler/PBO sources.

Each host receives one warmup and five measurements. The six gopurs host orders
cover all permutations; the Purust pair alternates. The public launchers select
hosts and GC policies; gopurs explicitly uses 8/8/8/8 workers and pipelining.
Only the internal `backend total` is published. Phase clocks may overlap.

Every case has `definition.json`, input manifests, per-run logs/manifests and a
`canonical-generated` directory. The runner retains a failed generation in
`failed-generated` before recording its mismatch. A fresh result-group name and
new case directory are required for retries, preserving the failed attempt.

Validation builds and runs Aff, Arrays, Enums, Promise, Prelude and Strings in
Go, builds the full generated b8x project, and builds/runs the Purust Aff suite.
These operations happen after measurement. The publisher requires all checks,
recomputes medians and totals, and audits the artifacts before writing the
public JSON/Markdown report and `ARCHIVE/README-next.md`. Apply that candidate
to `README.md` and verify its SHA-256 against `ARCHIVE/publication.json`.
Run `node bin/benchmark/compilation-refresh/audit.mjs "$ARCHIVE"` after applying
the candidate to check publication scope, medians, totals and historical evidence.
